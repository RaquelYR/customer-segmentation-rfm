# Segmentación de clientes con análisis RFM

## Descripción

Proyecto de análisis de clientes mediante el modelo **RFM (Recency, Frequency, Monetary)** aplicado a un dataset de transacciones de comercio online.

El objetivo es segmentar a los clientes según su comportamiento de compra e identificar perfiles relevantes desde una perspectiva de negocio, como clientes de alto valor, clientes con potencial de crecimiento y clientes en riesgo de abandono.

## Herramientas

- Python
- Pandas
- NumPy
- Matplotlib
- Jupyter Notebook

## Qué incluye el análisis

- Exploración y limpieza de datos.
- Construcción de las métricas RFM.
- Diseño de un sistema de scoring adaptado a la distribución de los datos.
- Segmentación de clientes.
- Comparación de los principales perfiles mediante visualizaciones.
- Interpretación de resultados y recomendaciones de negocio.

## Limitaciones

La segmentación se ha diseñado como una aplicación práctica del análisis RFM y podría refinarse en futuras iteraciones para obtener grupos más homogéneos.
